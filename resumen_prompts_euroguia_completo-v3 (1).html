Desarrollo Integral de EUROGUÍA UE

Este documento recoge todas las peticiones y soluciones técnicas aplicadas desde la creación inicial de la guía turística de los 27 países de la Unión Europea, pasando por la evolución de su motor de fotografías (Wikipedia + Wikimedia Commons), la gastronomía, el modo oscuro y las tradiciones, destacando exclusivamente el código fuente del mapa cartográfico interactivo (D3.js + TopoJSON).

Registro Completo de Prompts y Respuestas

1
Corrección de imágenes rotas y fuera de contexto (API Wikimedia)
Prompt del usuario:

«Bufff aún veo imágenes fuera de contexto de zonas turísticas concretas y hay algunos países que no tienen ni principal.»

Respuesta: Se eliminaron las URLs estáticas escritas a mano (que provocaban hashes rotos o fotos repetidas entre países) y se implementó una consulta dinámica a la API oficial de Wikipedia (fetchWikiLeadImage) para la foto principal de cada país y a Wikimedia Commons (gsrsearch) para las 3 fotos de cada zona, usando banderas HD (flagcdn.com) como respaldo instantáneo.

2
Curación por artículo real de Wikipedia (adiós carteles de senderismo)
Prompt del usuario:

«¿Qué es esto Gemini? Jajajajaja [mostrando un cartel metálico de perfil topográfico en lugar de una cala de Mallorca].»

Respuesta: Se sustituyó la búsqueda abierta gsrsearch (que devolvía carteles informativos o mapas) por un array de 3 artículos concretos de Wikipedia por zona (wikis: [...]) con prop=pageimages y respaldo bilingüe (es → en), garantizando 81 ubicaciones reales curadas como Cala Macarella o el Castillo de Neuschwanstein.

3
Duda sobre el reemplazo del bloque <script>
Prompt del usuario:

«¿Sustituyo el bloque script entero con el código que me has pasado?»

Respuesta: Se aclaró que no debía sustituirse entero, ya que borrar todo el <script> habría eliminado el mapa D3.js, la navegación SPA y los filtros. Se indicó reemplazar únicamente el diccionario EU_COUNTRIES y las funciones de carga de imágenes, cambiando .query por .wikis.

4
Optimización de tokens y localización exacta de líneas
Prompts del usuario:

«Tranqui Gemini tranqui, no consumas todos los tokens.» / «No lo encuentra, ¿me puedes indicar la línea?» / «Es que ese trozo no lo pegué porque no me quedó claro si hay que sustituir o simplemente añadirlo.»

Respuesta: Se precisaron las líneas exactas del archivo (línea 406 hasta la línea 685), aclarando que debía sustituirse para no duplicar constantes y actualizando las 2 llamadas a .wikis en las líneas 863 y 1207.

5
Personalización manual de miniaturas
Prompt del usuario:

«Indícame otra vez lo de cambiar las imágenes pequeñas, voy a poner algunas yo que no todas me cuadran.»

Respuesta: Se añadió una detección automática por expresión regular en fetchWikiLeadImage() para admitir tanto títulos de Wikipedia como URLs directas (https://...) o rutas de carpeta local (img/...).

6
Carrusel gastronómico con descripción dinámica
Prompt del usuario:

«¿Puedes añadir las comidas típicas en cada país? Intenta que haya un carrusel de imágenes que cambie la propia descripción cuando pase a otra; por ejemplo: está el de paella pone una descripción de la paella, está la de la tortilla de patatas con cebolla pone la descripción de la tortilla de patatas con cebolla.»

Respuesta: Se creó EU_FOODS_BY_COUNTRY con 3 platos típicos por cada uno de los 27 países (81 platos en total, incluyendo Paella Valenciana y Tortilla de Patatas con Cebolla) y un carrusel interactivo que actualiza foto, categoría, título y descripción al avanzar.

7
Modo oscuro y ajuste de contraste en etiquetas
Prompts del usuario:

«Ahora por último añade un modo oscuro.» / «Ayyy los textos de arriba a la izquierda con la bandera [adjuntando captura de texto blanco ilegible sobre fondo blanco].»

Respuesta: Se implementó darkMode: 'class' con botón Sol/Luna y persistencia en localStorage, corrigiendo de inmediato la clase .bg-white/95 en la pastilla flotante de la bandera para garantizar contraste en modo oscuro.

8
Sección de bailes y tradiciones típicas
Prompt del usuario:

«Hazme una última cosa, añade una sección de bailes/tradiciones de cada país.»

Respuesta: Se incorporó EU_TRADITIONS_BY_COUNTRY con 54 danzas y celebraciones folclóricas de los 27 Estados miembros (Flamenco, Vals Vienés, Tarantella, Sirtaki, Polka, Midsommar, etc.) y renderCountryTraditions().

9
Documentación HTML explicativa completa
Prompts del usuario:

«Mira a ver si puedes hacer un HTML explicativo sobre los prompts que te he mandado y las respuestas, no tienes que poner todo el código de la página (solamente destaca el código del mapa).» / «¿No puede incluir todos?» / «Es que hay más cosas, ¿te falta contexto?»

Respuesta: Con el contexto completo de las iteraciones previas recuperado, se consolidó esta bitácora HTML final con las 10 fases cronológicas completas del proyecto y el bloque de código fuente destacado del mapa interactivo D3.js.

10
Corrección de saltos de línea y actualización del resumen de prompts
Prompts del usuario:

«no gemini me referia a añadirle los promtps que te he pasado al resumen» / «me referia a añadirle los promtps que te he pasado al resumen» / «no me has generado nada» (adjuntando la bitácora HTML para incorporar los prompts y generar el archivo).

Respuesta: Se repararon los saltos de línea sin escapar en renderHomeFeatured() y loadCountryDetail() para garantizar la galería interactiva de 3 fotos por zona aleatoria, y se generó este archivo HTML descargable con todos los prompts integrados y el código destacado del mapa D3.js.

Arquitectura Cartográfica • D3.js v7 + TopoJSON

Código Destacado: Mapa Interactivo de la UE

Proyección Mercator centrada en Europa, carga de topología mundial con respaldo GeoJSON local, pines para microestados (Malta y Luxemburgo), zoom/arrastre y tooltip dinámico.

1. Proyección y Topología

Usa d3.geoMercator() centrada en [15.2, 52.8] y convierte datos TopoJSON (world-atlas) identificando los 27 países por su código ISO numérico (EU_BY_ISO).

2. Pines de Microestados

Añade círculos interactivos con coordenadas exactas para Malta y Luxemburgo facilitando su selección incluso sin hacer zoom.

3. Zoom y Tooltip Flotante

Integra d3.zoom() con escala [1, 7] y eventos mouseenter / mousemove / click que muestran bandera, capital, moneda y población junto al cursor.

map-engine.js (Fragmento principal del mapa D3.js) JavaScript / D3 v7 
async function initRealCartographicMap() {
    const container = document.getElementById('d3-eu-map-container');
    const loadingEl = document.getElementById('map-loading-state');
    const badgeEl = document.getElementById('map-source-badge');
    if (!container) return;

    d3MapInitialized = true;
    let countriesFeatures = null;

    // 1. Carga de cartografía TopoJSON con fallback GeoJSON local si no hay red
    try {
        const worldData = await Promise.any([
            fetchWithTimeout("https://cdn.jsdelivr.net/npm/world-atlas@2/countries-50m.json", 4500),
            fetchWithTimeout("https://unpkg.com/world-atlas@2/countries-110m.json", 4500)
        ]);
        countriesFeatures = topojson.feature(worldData, worldData.objects.countries).features;
        if (badgeEl) badgeEl.textContent = "Proyección Mercator Real • 27 Miembros UE";
    } catch (err) {
        countriesFeatures = getFallbackEuropeGeoJSON();
        if (badgeEl) badgeEl.textContent = "Cartografía Vectorial Local • 27 Miembros UE";
    }

    if (loadingEl) loadingEl.remove();

    const width = 880;
    const height = 600;

    // 2. Creación del lienzo SVG y proyección Mercator centrada en Europa
    d3Svg = d3.select("#d3-eu-map-container")
        .append("svg")
        .attr("viewBox", `0 0 ${width} ${height}`)
        .attr("preserveAspectRatio", "xMidYMid meet");

    const projection = d3.geoMercator()
        .center([15.2, 52.8])
        .scale(680)
        .translate([width / 2, height / 2]);

    const pathGenerator = d3.geoPath().projection(projection);
    const graticule = d3.geoGraticule().step([10, 10]);
    const mapGroup = d3Svg.append("g").attr("id", "eu-cartography-layer");

    // 3. Dibujo de meridianos/paralelos y polígonos de países
    mapGroup.append("path")
        .datum(graticule)
        .attr("d", pathGenerator)
        .attr("fill", "none")
        .attr("stroke", "#0f2347")
        .attr("stroke-width", 0.65);

    mapGroup.selectAll("path.country-shape")
        .data(countriesFeatures)
        .enter()
        .append("path")
        .attr("d", pathGenerator)
        .attr("class", d => {
            const iso = String(d.id).padStart(3, "0");
            return EU_BY_ISO[iso] ? "country-shape country-eu" : "country-shape country-non-eu";
        })
        .attr("data-country-id", d => {
            const iso = String(d.id).padStart(3, "0");
            return EU_BY_ISO[iso] ? EU_BY_ISO[iso].id : "";
        })
        .on("mouseenter", function (event, d) {
            const iso = String(d.id).padStart(3, "0");
            const country = EU_BY_ISO[iso];
            if (!country) return;
            highlightCountryOnMap(country.id, true);
            showMapTooltip(country, event);
        })
        .on("mousemove", function (event, d) {
            const iso = String(d.id).padStart(3, "0");
            if (EU_BY_ISO[iso]) positionMapTooltip(event);
        })
        .on("mouseleave", function (event, d) {
            const iso = String(d.id).padStart(3, "0");
            const country = EU_BY_ISO[iso];
            if (!country) return;
            highlightCountryOnMap(country.id, false);
            hideMapTooltip();
        })
        .on("click", function (event, d) {
            const iso = String(d.id).padStart(3, "0");
            const country = EU_BY_ISO[iso];
            if (!country) return;
            hideMapTooltip();
            navigateTo("detail", country.id);
        });

    // 4. Pines interactivos para microestados (Malta y Luxemburgo)
    const microstates = [
        { id: "mt", coords: [14.45, 35.9], label: "MT" },
        { id: "lu", coords: [6.13, 49.81], label: "LU" }
    ];

    microstates.forEach(ms => {
        const country = EU_COUNTRIES.find(c => c.id === ms.id);
        if (!country) return;
        const [cx, cy] = projection(ms.coords);

        const pinGroup = mapGroup.append("g")
            .attr("class", "cursor-pointer")
            .on("mouseenter", (event) => {
                highlightCountryOnMap(country.id, true);
                showMapTooltip(country, event);
            })
            .on("mousemove", (event) => positionMapTooltip(event))
            .on("mouseleave", () => {
                highlightCountryOnMap(country.id, false);
                hideMapTooltip();
            })
            .on("click", () => {
                hideMapTooltip();
                navigateTo("detail", country.id);
            });

        pinGroup.append("circle")
            .attr("cx", cx)
            .attr("cy", cy)
            .attr("r", 7)
            .attr("data-country-id", country.id)
            .attr("class", "microstate-pin");

        pinGroup.append("text")
            .attr("x", cx)
            .attr("y", cy + 16)
            .attr("text-anchor", "middle")
            .attr("fill", "#FFCC00")
            .attr("font-size", "8.5px")
            .attr("font-weight", "bold")
            .text(ms.label);
    });

    // 5. Control de Zoom y Paneo (arrastre)
    d3Zoom = d3.zoom()
        .scaleExtent([1, 7])
        .on("zoom", (event) => {
            mapGroup.attr("transform", event.transform);
        });

    d3Svg.call(d3Zoom);
}
